# PrintVis Link

PrintVis Link is a connectivity framework that allows PrintVis to communicate with external systems and applications. It provides APIs and integration endpoints for connecting PrintVis with web storefronts, customer portals, and third-party applications.

## Usage

PrintVis Link is used to:
- Connect PrintVis to web-to-print storefronts
- Expose PrintVis data and functionality to external systems via API
- Enable customer self-service portals to create and track jobs
- Integrate with marketing platforms and order management systems
