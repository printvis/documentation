# Kodak DPP Integration

The Kodak DPP (Digital Print Platform) integration connects PrintVis with Kodak's digital print workflow solutions, enabling automated data exchange for digital print production.

## Usage

The Kodak DPP integration is used by print shops running Kodak digital presses to:
- Automatically send job data from PrintVis to Kodak's production workflow
- Receive production status feedback from Kodak equipment
- Synchronize job specifications and production parameters
