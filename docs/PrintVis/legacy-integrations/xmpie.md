# XMPie Integration

XMPie is a leading platform for personalized marketing and variable data printing (VDP). The PrintVis XMPie integration connects PrintVis job management with XMPie's personalization workflows.

## Usage

The XMPie integration is used by print shops offering:
- Variable data printing (VDP) services
- Personalized direct mail campaigns
- Cross-media marketing campaigns (print + digital)

The integration enables:
- Automatic creation of XMPie campaigns from PrintVis jobs
- Status synchronization between PrintVis and XMPie
- Transfer of job specifications and variable data
