# Qualities

Qualities in PrintVis define quality grades for items, particularly paper and substrates. They provide an additional dimension for filtering and selecting materials in estimation.

## Usage

Qualities are used in:
- **Estimation** — Filter and select papers by quality grade (e.g., uncoated, coated, recycled)
- **Material Requirements** — Group requirements by quality for purchasing
- **Item management** — Organize and report on inventory by quality

## Setup

!!! warning "Assisted Setup Note"
    Item Qualities are covered in PrintVis Assisted Setup. Standard quality codes can be imported from the reference database.

Qualities are found by searching **PrintVis Item Qualities**.

### Field Descriptions

| Field | Description |
|---|---|
| **Code** | Unique identifier for the quality (e.g., UNCOATED, GLOSS-COATED, SILK-COATED). |
| **Description** | Full name of the quality grade. |
| **Sorting Order** | Controls the display order in selection lists. |
