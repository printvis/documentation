# Shipping Integrations

PrintVis supports integration with third-party shipping systems to automate label generation, rate shopping, and tracking. The primary shipping integrations are EasyPost, nShift Delivery, and nShift Ship.

## Usage

Shipping integrations allow you to:
- Get real-time shipping rates from carriers
- Generate shipping labels directly from PrintVis
- Automatically capture tracking numbers
- Track shipments through the carrier's system

### Supported Integrations

| Integration | Description |
|---|---|
| **EasyPost** | Cloud-based shipping API that supports multiple carriers (UPS, FedEx, USPS, DHL, and more). Generates labels and provides real-time rates. |
| **nShift Delivery** | European multi-carrier shipping platform. Handles parcel and freight shipments. |
| **nShift Ship** | nShift's advanced shipping module with additional carrier support and features. |

## Setup

### EasyPost Integration

EasyPost requires:
1. An EasyPost account and API key.
2. Configuration in PrintVis linking your PrintVis Shipping Agents to EasyPost carriers.
3. Carrier accounts linked in EasyPost.

### nShift Delivery Integration

nShift Delivery requires:
1. An nShift account and API credentials.
2. Configuration of carrier services in PrintVis.
3. Mapping between PrintVis Shipping Agents and nShift service codes.
