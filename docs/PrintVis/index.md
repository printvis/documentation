# PrintVis Documentation Overview

Welcome to the PrintVis Documentation. This area contains comprehensive documentation for setting up, configuring, and using PrintVis — the Microsoft-certified Business Management software built specifically for the print and packaging industry.

## How to Use This Documentation

The documentation is organized into the following categories:

| Category | Description |
|---|---|
| **Overview & Getting Started** | Introduction to PrintVis, the print industry, and how PrintVis integrates with Business Central |
| **Setup & Configuration** | General setup, feature management, assisted setup, users, permissions, and industry captions |
| **Case Management** | Case cards, status codes, order types, product groups, responsibility areas, departments, rejection codes, and QA |
| **Customers, Contacts & Vendors** | Managing customers, contacts, vendors, groups, and currency |
| **Estimation** | Complete estimation setup including templates, calculation units, price lists, and creating estimates |
| **Planning & Scheduling** | Production planning, planning board, milestones, capacity resources, and auto scheduling |
| **Warehouse & Purchasing** | Items, item type codes, material requirements, and purchasing |
| **Shop Floor & Job Costing** | Shop floor usage, work codes, WIP, and job costing |
| **Shipping** | Shipments, shipping agents, and shipping integrations |
| **Invoicing & Finance** | G/L posting setup, invoicing, and complaints |
| **Reports & Analysis** | Report setup, job tickets, and analysis pages |
| **System** | System-level configuration including units, fields, folder groups, and storage |
| **Legacy Integrations** | JDF, PrintVis Link, Web2PV, Esko, XMPie, Dynaway, and Kodak integrations |

## Article Structure

All articles in this documentation follow a consistent structure:

- **Usage** — How to use the feature in day-to-day operations
- **Setup** — How to configure and set up the feature
- **Examples** — Practical examples to illustrate usage

Where content is missing, articles are clearly marked so that the gaps can be identified and filled.
