# PrintVis Feature Management

The PrintVis Feature Management page allows you to enable or disable specific PrintVis standard functionality embedded in the base app. This is useful when specific functionality needs to be replaced by an additionally installed app, or to avoid unexpected interactions between features.

## Usage

Feature Management is used by administrators to control which standard PrintVis features are active in the system. When a feature is disabled, it is hidden from the user interface and does not interfere with replacement apps.

Access Feature Management by searching **PrintVis Feature Management** or by navigating to it from the PrintVis Admin Role Center.

If a feature is missing from the list, use the **Initialize Features** action to add new features that have been introduced in recent PrintVis updates.

## Setup

1. Search for **PrintVis Feature Management**.
2. Review the list of available features.
3. Select a feature and choose **Enable** or **Disable** as appropriate.
4. If expected features are not listed, click **Initialize Features** to populate the latest feature list.

!!! note "Important"
    Disabling a feature is typically only done when replacing standard PrintVis functionality with a custom or third-party app. Do not disable features unless you have a specific reason and a replacement in place.
