# Integrated Fields

Integrated Fields in PrintVis are fields that exist in both PrintVis and Business Central (or other integrated systems) and are kept synchronized. Understanding integrated fields helps avoid data inconsistencies when the same data exists in multiple places.

## Usage

Integrated Fields are relevant when:
- The same data is managed in both BC and PrintVis (e.g., customer name, contact details)
- Changes in one system should be reflected in the other
- Import/export or API integrations rely on specific fields
