# PrintVis Tools

PrintVis Tools (also called Dies) are physical production tools used in print and packaging — such as die-cutting tools, embossing dies, hot foil stamps, and custom cutting forms. PrintVis provides a tool management system to track these tools, their usage, and their association with specific jobs.

## Usage

The PrintVis Tools management system is used to:
- Register and track tools/dies owned by the print shop or customer
- Link tools to specific jobs (ensuring the correct tool is pulled for production)
- Track tool usage history and condition
- Manage tool storage and location
- Handle tool requests and approval workflows

### Tool Selection in Estimation

During estimation, tools can be selected for a job on the Job Card (Tool Selection feature). This links a specific tool to the job so it is automatically scheduled for use when production occurs.

See also: [Tool Selection](../../Pages/pvstoolselection.md) in the PrintVis Pages documentation.

## Setup

Tools are accessed via the PrintVis Tools page (search **PrintVis Tools**).

Key setup areas:
- **Tool No. Series** — Set in General Setup → Estimating section
- **Default Tool Step Across** — Set in General Setup for new die creation
- **Tool Storage Locations** — Locations where tools are stored
