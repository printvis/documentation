# Imposition Types

Imposition Types in PrintVis define how pages are arranged on a press sheet. The imposition type controls the layout of pages on the printing sheet, determining how sheets are folded and cut to produce the final product.

## Usage

Imposition Types are used in:
- Job Card setup — Each sheet/job item is assigned an imposition type
- Estimation — Imposition type affects how many pages fit on a sheet and the resulting sheet count
- Product Groups — A default imposition type can be set per product group
- Combined Sheets — Imposition type is critical for ganged jobs

### Common Imposition Types

| Type | Description |
|---|---|
| Sheetwise | Front and back printed with different plates (two runs) |
| Work and Turn | Same plate used for both sides (flip on long edge) |
| Work and Tumble | Same plate used for both sides (flip on short edge) |
| Perfecting | Both sides printed in one pass (perfecting press) |
| Signature | Multiple pages folded together into a signature |
