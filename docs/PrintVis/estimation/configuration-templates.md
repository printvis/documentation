# Configuration Templates

Configuration Templates in PrintVis allow you to define default settings for specific machine configurations that can be applied when a cost center configuration is selected in estimation. They streamline the setup of standard production scenarios.

## Usage

Configuration Templates are used when:
- A cost center has multiple possible configurations (e.g., a press that can run single-sided or double-sided, or with different feeder setups)
- You want to pre-populate estimation details automatically when a configuration is selected
- Standardizing the setup for common production scenarios
