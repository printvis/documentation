# Time Groups

Time Groups in PrintVis allow you to group time-based operations for reporting and analysis purposes. They are used to categorize time registrations (make-ready, run time, setup, etc.) for job costing reports and analysis.

## Usage

Time Groups are used to:
- Categorize job costing time entries by type (make-ready, production, setup, etc.)
- Generate reports that summarize time by group
- Compare estimated vs. actual time by category

Time Groups appear in:
- Job Costing Journal entries
- Job Costing reports
- Analysis pages that compare estimated and actual time

## Setup

Time Groups are found by searching **PrintVis Time Groups**.
